WWMM Remote 1.5.2 修订版增加了按设备免确认访问、后台运行和两端共用的 WWMM 图标。已有配对可以继续使用。

- **在被控端开启免确认。** 在设备列表选中自己的另一台电脑，打开「更多」，勾选「允许此设备免确认查看和控制本机」。也可以在收到控制请求时勾选记住权限，再点「允许并记住」。新配对和已有配对都默认逐次询问。取消勾选即可恢复，撤销配对也会清除权限。Mac 首次共享桌面和键鼠仍需系统的屏幕录制和辅助功能权限。
- **关窗后继续接收连接。** macOS 菜单栏和 Windows 系统托盘会保留应用图标。需要逐次允许的请求会唤起设备窗口。图标菜单可打开窗口、停止当前共享或退出应用。在 Windows 上左键图标打开窗口，右键打开菜单。
- **安装新版。** 下载文件名带 `1.5.2-r2` 且匹配本机架构的 ZIP。要让 Windows 免确认连接 Mac，请更新 Mac 端并在 Mac 上授权那台 Windows 电脑。两端更新后都能使用新图标和后台运行。
