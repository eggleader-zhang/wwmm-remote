WWMM Remote 1.0.0 支持在同一局域网内，从 Mac 或 Windows 电脑查看和控制另一台 Mac 或 Windows 电脑。两端先配对，每次连接由共享方确认。视频继续使用最高 1080p、60 fps 的 H.264 硬件编解码。

## 本版办公功能

- **文字剪贴板。** 控制会话中双方勾选「同步文字剪贴板」后，新复制的中文、多行文字和表格单元格可双向粘贴。单次上限为 1 MiB UTF-8 文本。结束会话会关闭同步。
- **多显示器。** 从查看窗口底部选择远端显示器。每次仅采集和传输一块屏幕。切屏时释放已按下的键和鼠标按钮，显示新画面后重新开放输入。拔掉选中的屏幕后，有其他可用屏幕时会切换过去。
- **最近设备和重连。** 「已配对设备」按最近使用排序并标出在线状态。点「重新连接」沿用上次的查看或控制模式，并向对方重新请求授权。
- **双向传文件。** 控制端可以把单个文件拖进查看窗口，共享端可以拖进设备页的会话工具栏。双方也可以点「发送文件」。接收方选定保存位置后开始传输，双方均可取消。应用核对 SHA-256 后保存。
- **办公回显。** 键鼠走独立连接，文件走后台磁盘线程，键鼠活动期间缩小文件发送分块。拖选或滚动停止后补一帧，改善静止文字的清晰度。

## 选择下载包

| 电脑 | ZIP 文件 |
| --- | --- |
| Apple 芯片 Mac，macOS 14.4 或更新 | `WWMM-Remote-1.0.0-macos-arm64.zip` |
| Intel Mac，macOS 14.4 或更新 | `WWMM-Remote-1.0.0-macos-x86_64.zip` |
| Intel / AMD 的 Windows 11 电脑 | `WWMM-Remote-1.0.0-windows-x64.zip` |
| ARM64 Windows 11 电脑 | `WWMM-Remote-1.0.0-windows-arm64.zip` |

Mac 解压后打开 **WWMM Remote.app**。Mac 作为共享端时需要允许屏幕录制，作为被控端还需要允许辅助功能。Windows 请解压整个目录，再打开 **WWMM Remote.exe**。遇到运行库缺失提示时，可以使用包内微软提供的对应架构 VC++ 运行库安装程序。

新功能需要两端均为 1.0。连接旧版时，0.4 可使用原有键鼠控制，0.3 可查看主屏幕。下载文件的 SHA-256 见 `SHA256SUMS.txt`。
