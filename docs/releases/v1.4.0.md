WWMM Remote 1.4.0 加入了自适应传输分辨率和原窗口重连。Mac 与 Windows 继续共用同一套局域网协议，支持跨系统和同系统连接。

- **办公画质。** 在会话中选择 1080p、1440p 或 4K 上限。传输持续丢包、抖动或积压时，画面会逐级降低分辨率，最低 720p。有连续约 8 秒的良好传输反馈后再升一级。静止桌面保留当前画面。同一块显示器调画质时，键鼠继续工作。
- **原窗口重连。** 局域网中断或电脑休眠后，原窗口等待已配对的那台电脑上线。点「重新连接」后，对方重新确认本次查看或控制。剪贴板和声音需重新开启。主动结束、拒绝或撤销信任会关闭会话。
- **兼容与下载。** 两端升级到 1.4 可使用全部功能。与 1.3 连接时沿用原来的画质选择。按处理器下载 Apple 芯片 Mac、Intel Mac、Windows x64 或 Windows ARM64 的 ZIP，四个包的校验值见随附的 SHA256SUMS.txt。
