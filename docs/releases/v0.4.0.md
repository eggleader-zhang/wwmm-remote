WWMM Remote 0.4.0 支持在同一局域网内控制已配对的 macOS 和 Windows 电脑。每次控制都由被控方确认。这个版本加入了键鼠控制、常用办公快捷键的自动适配和中文输入法选词上屏。

| 你的电脑 | 下载文件 |
| --- | --- |
| Apple 芯片 Mac（M 系列），macOS 14.4 或更新 | `WWMM-Remote-0.4.0-macos-arm64.zip` |
| Intel Mac，macOS 14.4 或更新 | `WWMM-Remote-0.4.0-macos-x86_64.zip` |
| Intel 或 AMD 的 Windows 11 电脑 | `WWMM-Remote-0.4.0-windows-x64.zip` |
| ARM64 Windows 11 电脑，例如骁龙电脑 | `WWMM-Remote-0.4.0-windows-arm64.zip` |

Mac 解压后打开 **WWMM Remote.app**。Windows 解压整个目录，再打开 **WWMM Remote.exe**。如果系统提示缺少 Visual C++ 运行库，先运行压缩包内对应架构的微软安装程序 `vc_redist.x64.exe` 或 `vc_redist.arm64.exe`。首次连接时，在「设备」页配对，选中对方，点「控制桌面」。Mac 作为被控端时需要允许屏幕录制和辅助功能。视频需要设备支持 H.264 硬件编解码。

macOS 包使用临时签名，未经 Apple 公证。Windows 应用未经 Authenticode 签名。各压缩包的 SHA-256 见 `SHA256SUMS.txt`。四个方向的双机键鼠体验与输入到画面的延迟仍待真机验收。
