WWMM Remote 1.5.1 简化了设备首页和远控窗口，并减少了待机和传输画面时的重复工作。

- **连接电脑。** 首页合并了附近和已配对的设备。同一台电脑只出现一次，最近用过的在线电脑排在前面。选中后可直接按上次的模式请求连接，另一种模式在「更多」中。首次配对的输入框只在需要时出现。
- **专心看画面。** 查看和控制窗口保留「会话选项」和结束按钮。切屏、画质、全屏、声音、剪贴板和发文件按会话能力显示在菜单里。收到文件时，接收和取消操作直接出现在画面下方。
- **减少后台开销。** 设备发现与监听共用一次网卡检查，列表只更新变化的行。静止画面停止刷新帧率，发送端释放过期的视频重传缓存。H.264 分包复用缓冲区，接收端直接在 UDP 读取缓冲区里解密。

按处理器下载 Apple 芯片 Mac、Intel Mac、Windows x64 或 Windows ARM64 的 ZIP。四个包的 SHA-256 见随附的 SHA256SUMS.txt。
