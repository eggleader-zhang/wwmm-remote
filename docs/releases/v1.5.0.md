WWMM Remote 1.5.0 为 macOS 和 Windows 的局域网办公会话增加显示器记忆、全屏和原始像素显示。

- **记住上次的显示器。** 在会话中选中副屏并看到画面。下次同一台已配对电脑获准连接时，共享端直接打开这块屏幕。屏幕暂时拔掉时使用主屏，原选择会保留。每台配对电脑分别保存，撤销信任会清除对应记录。此功能需要共享端使用 1.5，查看端支持切屏。
- **查看小字。** 在窗口底部的「显示」菜单选择「原始像素（1:1）」，每个收到的视频像素对应本机一个物理像素。可用水平或垂直滚动条平移画面，点「适应窗口」恢复完整画面。拖动、点击和滚轮定位使用同一套裁剪坐标。传输分辨率仍由画质菜单控制。
- **全屏办公。** 查看和控制都可在「显示」菜单中进入或退出全屏。滚动条、全屏和窗口尺寸变化在本机 GPU 上重绘已收到的画面，静止的表格也能立即平移。键鼠、剪贴板和声音保留各自的会话授权。

按处理器下载 Apple 芯片 Mac、Intel Mac、Windows x64 或 Windows ARM64 的 ZIP。四个包的 SHA-256 见随附的 SHA256SUMS.txt。
