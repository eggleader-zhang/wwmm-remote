WWMM Remote 1.3.0 为 Mac 和 Windows 的局域网桌面加入了双向截图粘贴、1440p 和 4K 画质，以及可按会话开启的系统声音。默认使用 1080p，声音关闭。新功能需要两端升级到 1.3.0，与 1.0 连接时仍可使用原有的文字剪贴板、切屏和文件传输。

## 在会话中使用

- **粘贴截图。** 控制方和共享方都勾选「同步文字和截图」。Mac 可按 `Control + Shift + Command + 4` 把选区截到剪贴板，Windows 可按 `Win + Shift + S`。在另一端的文档或聊天框正常粘贴即可。图片用无损 PNG 传输，支持透明背景。单张图片最多 1,677 万像素，PNG 最多 36 MiB。截图传输中仍可移动鼠标、滚动和打字。在控制窗口向远端粘贴时，如果截图仍在传输，保持原插入位置即可自动完成，转到其他位置或继续打字会取消这次待执行的粘贴。
- **切换画质。** 在查看或控制窗口底部选择「1080p · 办公」「1440p」或「4K」。所选值是传输上限，画面保留显示器宽高比，小屏按自身分辨率传输。拖动和滚动时会丢弃积压的旧画面，停下后补一张清晰的关键帧。硬件编解码失败时会尝试较低分辨率。
- **收听远端电脑。** 共享方勾选「共享系统声音」，查看方勾选「远端声音」，顺序不限。声音来自共享电脑正在播放的内容。任一方关闭即可静音，断开后清除授权。Opus 音频通过独立的加密 RTP 流发送，音频缓冲和丢包处理独立于画面与键鼠。

## 下载

| 电脑 | ZIP 文件 |
| --- | --- |
| Apple 芯片 Mac，macOS 14.4 或更新 | `WWMM-Remote-1.3.0-macos-arm64.zip` |
| Intel Mac，macOS 14.4 或更新 | `WWMM-Remote-1.3.0-macos-x86_64.zip` |
| Intel / AMD 的 Windows 11 电脑 | `WWMM-Remote-1.3.0-windows-x64.zip` |
| ARM64 Windows 11 电脑 | `WWMM-Remote-1.3.0-windows-arm64.zip` |

Mac 解压后打开 **WWMM Remote.app**。共享屏幕或系统声音需要允许「屏幕与系统音频录制」，共享键鼠需要允许「辅助功能」。Windows 请解压整个目录再打开 **WWMM Remote.exe**。遇到运行库提示时，可安装包内对应架构的微软 VC++ 运行库。四个 ZIP 的 SHA-256 见 `SHA256SUMS.txt`。
