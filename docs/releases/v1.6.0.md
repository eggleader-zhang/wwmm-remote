WWMM Remote 1.6.0 更新了远控窗口、文件传输和设备配对体验。已有配对和免确认授权可以继续使用。

- **多屏页签与控制中心。** 网易 UU 风格的顶部页签可直接切换远端显示器。打开可视化控制中心即可调整画质、显示和会话选项。
- **连接信息浮窗。** 灰色半透明浮窗显示实时延迟、丢包、码率和连接参数，趋势图同时记录延迟和视频码率。可在控制中心选择浮窗位置。
- **全屏与深色模式。** 全屏顶部栏在空闲时自动收起，鼠标移到顶部即可展开，也可固定。界面跟随系统深浅色。
- **传文件与剪贴板。** 一次选择或拖入多个文件，按队列依次发送。可在「本机 → 设置」或远控会话菜单中开启「连接时自动开启剪贴板同步」。
- **被控端隐私条。** 共享或被控制时，被控端的悬浮条显示当前会话，可一键停止共享。
- **设备列表与配对。** 卡片显示设备系统、在线状态和「免确认」授权。双击已配对的在线设备或在列表中按回车即可发起连接。本机配对码卡片支持一键复制并显示剩余时间，粘贴带空格或短横线的配对码会自动清洗。
- **macOS 权限检查。** 在「本机 → 权限检查…」查看屏幕录制和辅助功能授权，按「重新检测」刷新。屏幕录制、辅助功能与本地网络均可从这里打开对应的系统设置。
