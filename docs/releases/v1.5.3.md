首次安装和升级都可以离线完成。Windows 安装程序自动选择 x64 或 ARM64。Mac 磁盘映像同时支持 Apple 芯片和 Intel。

- **Windows** 双击 `WWMM-Remote-Setup.exe`，按提示安装并打开。安装程序面向当前用户，自带运行库，开始菜单中会出现 WWMM Remote。
- **macOS** 打开 `WWMM-Remote.dmg`，将 WWMM Remote 拖到「应用程序」，再从那里打开。首次共享桌面时按系统提示授予屏幕录制和辅助功能权限。
- **从 1.5.2-r2 迁移** 结束会话，在两端各自的托盘或菜单栏中退出旧版，然后使用新安装包。已有设备身份、配对及免确认授权保存在当前用户账户中。
- **以后升级** 从菜单栏或系统托盘选择「安装更新…」，选择本机、U 盘或共享目录中的新版 DMG 或 EXE，确认后重新启动。会话和文件传输进行中可以排队，点击同一菜单项可取消等待。应用离线核验发布流水线签名和构建号。
