Windows 控制 Mac 时，点进远控画面即可使用 Mac 快捷键。窗口模式和全屏都支持。

| Windows 键 | Mac 收到的键 |
| --- | --- |
| Alt | ⌘ Command |
| Win | ⌥ Option |
| Ctrl | ⌃ Control |
| Shift | ⇧ Shift |

- 按住 Alt 连点 Tab 切换 Mac 应用，加 Shift 反向选择，松开 Alt 确认。Alt+C 和 Alt+V 在 Mac 上复制和粘贴。左右修饰键独立，Mac 应用自定义的组合键也按这套对应关系发送。
- Windows 的「设备 → 本机 → 设置 → 自动映射 Mac 按键关系」默认开启。关闭后立即恢复原有办公快捷键，设置会在下次启动时沿用。
- 点回本机窗口，或在远控画面按 Ctrl+Alt+Shift+F12，可将键盘交还 Windows。Windows 的 Ctrl+Alt+Delete 由本机系统处理。
- Windows 与 Mac 都升级到 1.5.4 后启用完整映射。连接旧版时使用原有快捷键。已安装 1.5.3 的用户可以从托盘或菜单栏选择「安装更新…」。
