WWMM Remote 1.6.1 新增远控帧率调节，并修复 macOS 局域网发现中的能力协商字段解析。已有配对和免确认授权可以继续使用。

- **三档帧率调节。** 两端升级到 1.6.1 后，可在控制中心切换 `30 fps`、`60 fps`（默认）和 `120 fps`，码率上限会随帧率自动适配，连接信息浮窗同步显示目标帧率上限。
- **自动回退兜底。** 选用 `120 fps` 时，如果共享端显示器刷新率低于 90 Hz 或任一端硬件编解码无法维持高帧率，会自动平滑回退至 `60 fps` 并提示，不中断当前会话。
- **高刷呈现与发现修复。** 扩大 macOS Metal 和 Windows D3D11 交换链缓冲以改善高帧率流畅度；修复 macOS Bonjour 发现解析时遗漏实时延迟（RTT）与帧率能力字段的问题。
